Optional Catppuccin palettes
===========================

Source: https://github.com/catppuccin/moon-animator-2
Commit: 7541ad7e017c3447cf53f0c4b79ee2963fe7528b

These four JSON files contain only six RGB colors each. The candidate includes
the same colors as named Catppuccin presets in its theme menu; Default remains
the initial theme. The files are retained for inspection and manual import.
The accompanying MIT license belongs to the Catppuccin theme
project; it does not license the Moon Animator engine.

In Moon Animator, open Options > Other > Edit Theme, paste the contents of one
JSON file into the Import textbox, then save the theme. This follows the
upstream README. Theme handling passed isolated module tests; this UI flow
still needs a Roblox Studio check.
