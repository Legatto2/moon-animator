# Official tutorial coverage

This source review maps the chapters of [Moon Animator 2 Basics — Official Tutorial](https://www.youtube.com/watch?v=q8tGNMo_jHg), published by six on 2021-12-21, to the pinned v34000 baseline and this maintained candidate.

**All twelve editing workflows named after the installation chapter have corresponding implementations in the baseline.** No missing feature was established from the available chapter description. The hardening keeps these mechanisms and adds a focused Easy Weld input check described below.

## Evidence and limits

The comparison uses the retrieved first-party video description and manual inspection of the source extracted from `Moon Animator 2 (v34000).rbxm`, originally pinned at `69b88295776351b5aec1cdff783bb12a194daf43`. A transcript and visual playback were not available. This is a source coverage check, not a frame-by-frame comparison, a current Studio tutorial, or a completed Studio acceptance test. Buttons, shortcuts, platform installation steps, and remote asset permissions still need checking in Studio.

The links below point to the candidate's `reviewed-sources` snapshot. `verify.py` compares that snapshot against every script extracted from the rebuilt candidate, so the reviewable files and packaged scripts must agree.

## Focused correction found during this comparison

The original Easy Weld selection handler enables **Clean Tool** for any selected Tool, Model, or Folder. Its cleaner then assumes that at least one descendant is a BasePart. An empty container, or a container holding only non-part objects, leaves `newBasePart` unset and reaches `newBasePart.Position`.

The maintained patch validates the selected cleaning inputs before creating replacement models or changing the scene, and reports an understandable error for a container with no BaseParts. This addresses an existing input error in a tutorial-covered tool; it does not add a duplicate welding system. Focused mocked tests cover rejected input and preserved normal joint/cleaning behavior. Studio behavior remains to be checked.

## Event compatibility

The named markers shown in the chapter list remain available without enabling restricted event-command preview. The new data-only sound/particle commands are an additional local-preview mechanism. Existing arbitrary Luau event text remains stored, but this candidate does not execute it. A user must approve supported commands locally for the current session; importing a project does not grant that approval.

No other missing mechanism has been verified from this video's available metadata. A Studio walkthrough of these chapters is still useful before calling the candidate a fully tested replacement.
